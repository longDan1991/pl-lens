## 待写提纲

- 生命周期省略规则：80% 场景编译器自动推断，无需手写 `'a`
- 多输入引用交集反例：`longer<'a>(x: &'a str, y: &'a str) -> &'a str` 返回值寿命受限于**更短**一方
- 结构体借用实战：`struct LogEntry<'a> { level: &'a str }` 防止悬垂指针
- `'static` 常见误区：字符串字面量与泛型约束 `T: 'static` 的区别
