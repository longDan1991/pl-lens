# 三、资源管理与安全边界

> 切入路径：**Go → Rust → C++**

按复杂度递增观察三套完全不同的资源回收哲学：运行时自动回收、编译期仿射类型证明、确定性析构与移动语义。

## 本章核心议题

1. **Go：逃逸分析 + 三色标记 GC**：编译器如何决定值放栈上还是堆上，GC 暂停与吞吐的权衡。
2. **Rust：所有权、借用与生命周期**：把“共享不可变 / 可变不共享”编码进类型系统，零运行期开销换编译期约束。
3. **C++：RAII 与 Move Semantics**：用作用域析构管理任意资源（内存、锁、文件句柄），对比 Rust 的所有权转移。
4. **经典试金石**：哈希表 + 双向链表（LRU Cache）在 6 门语言中的别名冲突与解法。
