# 二、内存模型与值语义

> 切入路径：**C（建立所有系统语言的底层对照组）**

不理解栈帧、堆布局、指针别名与未定义行为（UB），就很难看清 Go GC、Rust 借用检查器和 C++ RAII 各自在用什么代价修补什么问题。

## 本章核心议题

1. **栈帧与堆分配**：生命周期如何绑定到调用栈，何时必须逃逸到堆。
2. **值语义与指针别名（Aliasing）**：为什么可变别名同时破坏内存安全与编译器优化。
3. **结构体对齐与内存布局**：padding、tagged union 的大小计算、缓存局部性。
4. **Undefined Behavior（UB）**：悬垂指针、越界读写、有符号整数溢出与编译器假设。
