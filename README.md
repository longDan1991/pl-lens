## 3.顺序表的操作

## 4.链表的操作

1. A和B是两个元素递增的单链表。设计一个算法，将A和B归并成一个按元素值递增的链表C。（知识点：1.尾/头插法建立单链表；2.单链表的归并操作）
2. 查找链表C（带头节点）中是否存在一个值为X的节点，若存在，则删除该节点并返回1，否则返回0。（知识点：1.链表中节点的查找；2.删除节点）
3. 双链表的创建、查找、插入、删除。
